# cordion

🚀 A high-performance, feature-packed Discord bot library for Rust.

## Why cordion?

While other major Discord bot libraries like `serenity` and `twilight` exist, building slash commands with them can feel unintuitive, and they are often slow to keep up with changes to Discord's JSON models. This project was created to solve those issues while providing a high-performance, modern alternative.

We are still in the early stages of development, but we are working hard to build something better by learning from the foundational designs of existing libraries.
